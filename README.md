# Breathe ESG Prototype

A Django + React prototype for ingesting and reviewing enterprise emissions data.

---

## Features

- JWT Login
- CSV Upload
- Dashboard Analytics
- Suspicious Record Detection
- Charts and Visualizations
- Analyst Review Workflow

---

## Tech Stack

Frontend:
- React
- Vite
- Recharts

Backend:
- Django
- Django REST Framework
- SimpleJWT

Deployment:
- Vercel (Frontend)
- Render (Backend)
